# Chalet To Go — Ofício alpino

- `logo.svg`: shared website asset, shield only. Contains an embedded transparent PNG, not vectorized paths.
- `logo-escudo.png`: transparent shield source.
- `logo-horizontal.png`: approved original horizontal signature on white, before the color experiments.
- `logo-anterior.svg`: preserved former geometric brand asset.

The site and magazine apply a white CSS filter in night mode; virtual cards use the same white treatment against their green background. Header and card styles contain the full oval without cropping.

The shield was extracted using the built-in ImageGen tool from the approved green vertical composition. Prompt: extract the oval only, remove lettering, preserve the artwork and line weights, use forest green, and make all white areas transparent, including internal negative space. No ribbon or brown details.
